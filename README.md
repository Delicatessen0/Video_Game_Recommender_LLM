**NextLevel** is a sophisticated video game discovery platform that leverages the power of Large Language Models (LLMs) to provide deeply personalized recommendations based on natural language queries. No more generic "Top 10" lists—just games you'll actually love.

Live version:
https://video-game-recommender-llm.onrender.com/

You can also navigate to Releases and download the source code and app.exe. You can then open app.exe to run the program that way.

Backend: Python / Flask
Artificial Intelligence: Llama-3.3-70B (via Hugging Face Inference API)
Data Source: Steam Web API
Frontend: HTML5, CSS3, JavaScript
Deployment: Render-ready (via `Procfile`) / Local Executable (via `PyInstaller`)
